1 本地 Hugo 项目

选择 Hugo 项目根目录（含 hugo.yaml 和 content 的那一层）。程序会读取里面的域名和网址格式。

2 Hugo 程序

通常放在项目根目录，留空会自动探测。

Git 程序一般自动探测，找不到时可手动指定 git.exe：

3 GitHub Token

用于把生成的页面提交到你的仓库。GitHub → Settings → Developer settings → Personal access tokens，勾选 repo 权限。留空表示不修改已保存的 Token。

4 选择仓库
5 网络代理（国内通常必填）

国内直连 GitHub 通常不通。填代理软件的 HTTP 地址，例如 http://127.0.0.1:7890。能直连就留空。

6 博客参数 （一般自动读取，可手动改）
